# 자막 초안

시각은 녹화 순서 기준의 대략이다. 편집 앱에서 화면을 보며 맞춘다.

| 시각 | 장면 | 자막 |
|---|---|---|
| 0:00 ~ 0:04 | 홈 (오늘 할 일과 주간 도리 줄) | 오늘 할 일, 한눈에 |
| 0:04 ~ 0:12 | 새 할 일 적기 | 카테고리 색으로 척척 적고 |
| 0:12 ~ 0:17 | 체크하면 진행 막대가 참 | 끝낼 때마다 도리가 채워져요 |
| 0:17 ~ 0:23 | 어제 못 끝낸 일을 모두 오늘 하기 | 못 끝낸 일은 한 번에 오늘로 |
| 0:23 ~ 0:30 | 친구 화면에서 반응 보내기 | 친구가 끝낸 일엔 응원을 |
| 0:30 ~ 끝 | 로그인 화면 | 모도리 — 친구와 함께 매일을 채워가요 · modori.site |

푸시 알림·타이머·일기·AI는 말하지 않는다(없는 기능이거나 제외 기능).
