# AI 영상 프롬프트 (Kling 등)

30초 = 5초 컷 6개를 이어 붙인다. 형식은 세로 9:16, 각 컷은 5초.
공식(피사체 · 피사체 움직임 · 장면 · 카메라 · 조명/분위기)과 60~100단어, 명확한 카메라 용어는
Kling 프롬프트 가이드(atlascloud.ai/ko/blog/tips/kling-ai-video-prompt-guide)를 따랐다.

## 콘셉트: "색이 채워지는 하루"
회색으로 시작한 하루가 할 일을 끝낼 때마다 카테고리 색(파랑·초록·주황·보라)으로 물든다. 모도리 앱의 도리가 색으로 차오르는 것과 같다.
글자·로고·앱 화면은 AI가 깨뜨리기 쉬워서 **전부 편집에서 얹는다**(프롬프트에 글자를 넣지 않는다).

## 공통 (모든 컷 앞에 붙이거나 스타일 지정에 쓴다)
- 스타일: 따뜻한 파스텔 톤, 부드러운 필름 그레인, 얕은 피사계 심도, 젊고 밝은 브랜드 광고
- 색 팔레트: 파랑 #2563eb, 초록 #22c55e, 주황 #f97316, 보라 #7c3aed, 바탕은 오프화이트

## 네거티브 프롬프트 (모든 컷 공통)
```
흐릿함, 왜곡된 얼굴, 뒤틀린 손가락, 여섯 번째 손가락, 글자, 자막, 로고, 워터마크, 갑작스러운 컷, 깜빡임, 과한 채도, 저해상도
```

## 컷별 프롬프트

**컷 1 (0~5초) 회색 아침, 훅**
```
어수선한 나무 책상 위 포스트잇과 연필, 모든 것이 채도 없는 회색 톤, 손 하나가 펜을 든 채 망설이며 멈춰 있다, 창가의 차가운 아침 빛, 탑다운에서 천천히 내려오는 슬로우 푸시 인, 얕은 피사계 심도, 고요하고 답답한 분위기, 35mm 필름 그레인
```

**컷 2 (5~10초) 적는 순간 색이 번진다**
```
스마트폰 화면에 손가락이 할 일을 입력하자 파랑·초록·주황·보라 잉크가 화면에서 번져 나와 책상 위 물건들을 물들인다, 밝은 아침 창가 빛, 폰 화면 위에서 매크로 클로즈업으로 시작해 뒤로 빠지는 부드러운 풀 백, 색이 폭발하듯 퍼지는 에너지 넘치는 분위기, 깨끗한 오프화이트 배경, 밝은 톤
```
※ 폰 화면 속 글자는 흐릿하게 두고 편집에서 실제 앱 화면 녹화를 덮는다.

**컷 3 (10~15초) 도리 등장, 몸이 색으로 차오른다** (이미지→영상 권장: 시작 프레임에 도리 그림)
```
흰 고양이 캐릭터가 눈을 감고 웃으며 몸통이 아래에서부터 파랑, 초록, 주황, 보라 색으로 차오른다, 색 물결이 올라갈 때 작은 반짝임 입자가 흩날린다, 미세한 바운스, 정면 미디엄 숏에서 슬로우 푸시 인, 부드러운 키 라이트와 림 하이라이트, 귀엽고 따뜻한 분위기
```
※ 이미지→영상은 "사진이 아니라 동작과 카메라를 묘사"하는 규칙에 맞춰 캐릭터 생김새 설명은 뺐다.

**컷 4 (15~20초) 친구와 함께**
```
교실 창가 옆에서 두 친구가 각자 스마트폰을 서로 보여 주며 웃고 하이파이브를 한다, 화면에서 하트와 불꽃 모양 빛이 떠오른다, 오후의 따뜻한 역광, 인물 옆을 따라가는 트래킹 숏, 35mm, 얕은 피사계 심도, 다정하고 생기 있는 분위기
```
※ 얼굴이 깨지기 쉬우니 뒷모습·옆모습·손 위주로 뽑고, 얼굴이 나오면 컷 길이를 짧게 쓴다.

**컷 5 (20~25초) 몽타주: 도서관·운동·카페**
```
도서관에서 책을 덮는 손, 운동장에서 줄넘기를 마치는 다리, 카페에서 노트북을 닫는 손이 빠르게 이어지고 각 장면 끝에 파랑, 초록, 주황 색이 팝 하고 터진다, 빠른 휩 팬 전환, 핸드헬드 미세한 흔들림, 밝은 자연광, 경쾌하고 활기찬 분위기
```
※ 한 번에 안 되면 도서관·운동·카페를 각각 2~3초 컷으로 나눠 뽑는다.

**컷 6 (25~30초) 엔딩, 색으로 가득한 저녁**
```
노을이 드는 창가에 흰 고양이가 앉아 창밖의 색색으로 물든 도시를 바라보며 만족스럽게 눈을 감는다, 골든 아워 따뜻한 역광, 뒤에서 앞으로 천천히 도는 소프트 오르빗, 얕은 피사계 심도, 포근하고 벅찬 분위기, 마지막 1초 화면이 부드럽게 밝아진다
```
편집에서 마지막 1.5초에 로고와 "친구와 함께 매일을 채워가요", modori.site를 얹는다.

## 편집 방법 (CapCut 등)
1. **컷 이어 붙이기:** 컷 사이는 색이 번지는 전환(컬러 와이프)이나 휩 팬으로 잇는다. 컷 5는 0.3~0.5초 단위로 자른다.
2. **속도 조절:** 컷 2의 색 번짐 순간은 0.5배 슬로우로 늘렸다가 컷 3으로 넘어갈 때 2배로 당기는 "속도 램프".
3. **실제 앱 화면 끼워 넣기:** 컷 2와 컷 4의 폰 화면 위에 `docs/promo/modori-promo.mp4`의 해당 장면을 폰 화면 모양에 맞춰 얹는다(마스크·트래킹).
4. **글자 애니메이션(키네틱 타이포):** 컷마다 한 줄씩 굵은 글씨로 뜨고 사라지게 한다.
   - 컷1 "오늘도 뭐부터 하지?" → 컷2 "적으면" → 컷3 "채워지고" → 컷4 "친구와 함께면 더" → 컷5 "하나씩 끝낼 때마다" → 컷6 "모도리 · 친구와 함께 매일을 채워가요"
5. **소리:** 컷 전환마다 쓱(swoosh), 색이 터질 때 뿅(pop), 체크할 때 딸깍 효과음. 음악은 하나로 이어 깐다.
6. **색 보정:** 전 컷에 같은 필터(따뜻한 톤, 약한 필름 그레인)를 얹어 컷마다 색이 달라 보이는 것을 맞춘다.

## 음악 프롬프트 (Suno 등 음악 생성)
```
밝고 경쾌한 팝 인스트루멘털, 110 BPM, 통통 튀는 피아노와 핑거 스냅, 부드러운 베이스, 후반에 벅차게 커지는 빌드업, 30초, 청춘 광고 음악, 보컬 없음
```
상업적 이용 가능 여부는 사용하는 서비스의 약관과 요금제로 확인한다.

## 주의
- 타이머·일기·리마인더·AI 기능, 푸시 알림은 영상에 넣지 않는다(제외 기능이거나 아직 없는 기능).
- 결과물에 실제 인물의 얼굴이나 상표가 닮게 나오면 쓰지 않는다.
- 도리가 컷마다 다르게 나오면 컷 3·6은 도리 그림을 시작 프레임으로 넣는 이미지→영상으로 뽑는다.
