# 플랫폼별 기능 분담

웹(modori.site), 데스크톱 앱(`desktop/`, Electron), 모바일 앱(지금은 없음. 스토어 출시는 학교 계정으로 준비 중)이
무엇을 나눠 맡는지 정한다. 2026-09-29 초안.

## 원칙

- **기능은 웹에 한 번만 만든다.** 데스크톱·모바일 앱은 웹을 띄우는 껍데기라, 할 일·소셜 기능은 어디서나 똑같다.
  앱마다 따로 만들면 세 벌을 고쳐야 하고 어긋난다.
- 앱은 **그 플랫폼에서만 되는 것**(창, 로그인 넘겨받기, 푸시, 설치)만 맡는다.
- 제외 기능(CLAUDE.md 규칙 7)은 어느 플랫폼에도 넣지 않는다. 푸시는 친구가 보낸 반응·새 팔로워를 알리는 데만 쓴다.

## 나눔

| 기능 | 웹 | 데스크톱 | 모바일 |
|---|---|---|---|
| 할 일·카테고리·루틴·일정·메모·기록 | ✅ | 웹과 같음 | 웹과 같음 |
| 소셜(팔로우, 친구 화면, 반응, 알림 목록) | ✅ | 웹과 같음 | 웹과 같음 |
| 화면 배치 | 폭에 맞춤(넓으면 왼쪽 달력) | 넓은 화면 배치 | 좁은 화면 배치(주간 줄) |
| 로그인 | Google·DataGSM | 평소 브라우저에서 로그인 → `modori://`로 넘겨받기 ✅ | 스토어 앱: 같은 넘겨받기를 앱 링크로. iOS는 Apple 로그인도 필요(가이드라인 4.8) |
| 새 알림 표시 | 아래 탭 숫자 ✅ | 아래 탭 숫자 | 아래 탭 숫자 + **푸시 알림**(반응·새 팔로워, 짧은 시간 안의 반응은 묶음) |
| 설치 | — | 마이페이지 "Windows 앱 받기" ✅ | 스토어. 스토어 전에는 홈 화면에 추가(PWA) 안내 |
| 연결이 끊겼을 때 | 브라우저 기본 화면 | 안내 화면 ✅ | 안내 화면 |
| 업데이트 | 배포하면 바로 | 화면은 바로(웹). 앱 껍데기는 새 설치 파일 | 화면은 바로(웹). 앱 껍데기는 스토어 업데이트 |

✅ = 지금 있음.

## 정하지 않은 것

- 데스크톱 푸시 알림: 창이 닫혀 있으면 받을 수 없고, 열려 있으면 아래 탭 숫자로 충분해서 지금은 넣지 않는다.
  데스크톱에서도 원하는 사람이 많으면 다시 본다.
- 홈 화면 위젯: 스토어 앱이 나간 뒤에 본다. iOS(Swift)·Android(Kotlin)를 따로 만들어야 하는 큰 작업이다.
- 모바일 스토어 출시 방식: Capacitor로 웹을 감싸는 쪽을 권한다(데스크톱과 같은 구조). 계정 명의가 정해지면 결정 기록에 남긴다.
