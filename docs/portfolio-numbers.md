## 이야기 소재 (면접에서 풀 만한 것)

- **장애 8건과 재발 방지**: 배포 스크립트가 DB보다 먼저 마이그레이션을 돌린 문제(INC-4), 검증이 취소되면 배포가 빠지는 문제(INC-6), 매월 1~9일에만 깨지는 달력 테스트(INC-7).
- **빠르게 느껴지는 법**: 서버를 늘리지 않고 원인을 재서(VM 한가함 → 요청 왕복이 원인) 탭 미리 받기·체크 즉시 이동을 했다. 한 번은 전역 캐시를 켰다가 가입 직후 온보딩에 갇히는 버그를 E2E가 잡아 되돌렸다(`decisions.md`).
- **빌드 경고를 흘려보내지 않기**: 백업 감시를 만들다가 로컬 빌드에서 "프로젝트 전체를 서버 번들에 넣는다"는 경고가 떴고, 공식 안내대로 고쳤다. 운영 이미지를 직접 열어 보니 운영은 원래 영향이 없었다는 것까지 확인해 기록을 바로잡았다.
- **프라이버시를 지킨 지표 설계**: 화면별 이동 기록 대신 가입 단계·쓴 날짜만 센다. 이유와 대가를 문서로 남겼다(`metrics.md`).
- **테스트를 고쳐 통과시키지 않는 규칙**: 테스트가 실패하면 구현을 고친다. 동작이 바뀌어 고친 테스트는 요청 기록에 이유를 적었다.
