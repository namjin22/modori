# 개인정보 목록

실제로 저장하는 개인정보를 코드와 스키마에서 확인한 것만 적는다. 2026-09-28 기준.
새 필드나 새 저장소를 만들면 이 문서와 개인정보처리방침(`lib/privacy.ts`)을 같이 고친다(CLAUDE.md 규칙).

### 데이터베이스 밖

| 항목 | 어디 | 보관 기간 |
|---|---|---|
| 로그인 쿠키 | 브라우저 (`__Secure-authjs.session-token`) | 세션과 같다 |
| 테마(라이트·다크) | 브라우저 localStorage | 브라우저가 지울 때까지 |
| 가입 경로 표시(`modori-from`) | 브라우저 localStorage. 링크의 `?from=` 값(또는 앱 안에서 연 화면 표시)을 처음 한 번 적고, 가입할 때 서버로 보낸다. 쿠키가 아니다 | 브라우저가 지울 때까지(가입 뒤에도 남지만 다시 쓰이지 않는다) |
| 컴퓨터 알림 켬 표시(`modori-desktop-notify`) | 브라우저 localStorage. 알림 화면의 "이 기기에서 알림 띄우기"를 켠 기기에만 `push:<계정 id>`(웹 푸시) 또는 `on:<계정 id>`(창이 열려 있을 때만)를 적는다(다른 계정으로 로그인하면 꺼진 것으로 본다). 끄면 지운다. 서버로 보내지 않는다. 알림 문구는 기존 알림(반응·팔로우·친구가 끝낸 일)에서 만들고 모도리는 새로 저장하지 않는다. 다만 띄운 알림(친구 닉네임, 공개 카테고리의 할 일 내용)은 운영체제의 알림 기록에 남을 수 있다 | 브라우저가 지울 때까지 |
| 시간대 안내 거절 표시(`modori-tz-dismissed:<시간대>`) | 브라우저 localStorage. "지금 그대로"를 누른 기기 시간대에 대해 같은 안내를 다시 묻지 않으려는 값. 쿠키가 아니다 | 브라우저가 지울 때까지 |
| 접속 IP·세션 값 | 서버 메모리의 요청 속도 제한(`lib/rate-limit.ts`) | 10분 안쪽, 재시작하면 사라짐. 저장하지 않는다 |
| 서버 프로그램 기록 | Docker 로그(json-file 10MB × 3) | 30MB를 넘으면 오래된 것부터 |
| 백업 | VM `/opt/modori/backups`(파일 권한 600), 백업용 Neon | VM 7일, Neon은 최신 한 벌(매일 덮어씀) |

Cloudflare(접속을 잇는 곳)와 Google·Apple·DataGSM(로그인), 글꼴을 내려받는 jsDelivr(IP·브라우저 정보가 전달됨, 우리는 저장 안 함)는 방침 5번에 적었다. 반응을 보낸 사람의 닉네임은 그 할 일 주인의 팔로워에게 보인다(방침 4번). 데스크톱 앱(Windows)은 새 버전이 있는지 확인하고 업데이트 파일을 받으려고 GitHub(github.com)에 접속하며, 접속 주소(IP)와 앱 정보가 GitHub에 전달된다(우리는 저장하지 않는다). electron-updater가 기본으로 만드는 설치별 무작위 번호(.updaterId)는 만들지도 보내지도 않게 껐다(2026-10-27. 방침 5번). 푸시 알림은 Android는 Google(Firebase Cloud Messaging), iOS는 Apple(APNs)이 기기에 전달한다(알림 문구: 닉네임과 "반응/팔로우" 안내 한 줄, 할 일 리마인드는 "오늘 할 일이 N개 남았어요" 한 줄 — 할 일 내용은 넣지 않는다. 내가 정한 알림은 **내가 쓴 문구**가 그대로 들어가고 다른 사람에게는 가지 않는다(2026-10-26). 웹 푸시는 잠가 보내 푸시 서버가 못 보지만, FCM·APNs에는 문구가 평문으로 가는 것으로 본다. 친구 끝냄 알림은 친구 닉네임과 **그 친구가 공개 카테고리에서 끝낸 할 일의 내용**(팔로워가 친구 화면에서 이미 볼 수 있는 것)이 들어간다, 2026-10-17. 이것도 방침 5번).

## 2. 없앨 수 있는 것

| 항목 | 상태 | 한 일 / 남은 일 |
|---|---|---|
| `User.name` (실명) | 어디서도 쓰지 않는다. 운영 10명 모두 저장돼 있었다 | 2026-09-28부터 새로 저장하지 않는다(`lib/auth-minimal.ts`). **이미 저장된 값을 비울지는 사용자 결정** |
| `User.image` (Google 사진 주소) | 쓰지 않는다. 운영 4명 | 위와 같음 |
| `Account` 토큰(access·refresh·id_token 등) | 로그인 뒤 Google·DataGSM API를 부르지 않아 쓰지 않는다. DataGSM refresh_token은 오래 산다 | 새로 저장하지 않는다(예외: Apple의 refresh_token, 계정 지울 때 연결을 끊는 데만 쓴다). **이미 저장된 토큰(운영 10개 계정)을 비울지는 사용자 결정** — 비우는 것을 권한다 |
| `User.grade`, `classNum` | 쓰지 않았고 운영에 값도 없었다 | 2026-09-29 사용자 승인으로 열을 지웠다(마이그레이션 `20260929120000_drop_grade_class`) |
| `User.emailVerified`, `VerificationToken` 표 | 이메일 로그인용. 쓰지 않고 비어 있다 | Prisma 어댑터가 기대하는 모양이라 둔다 |
| 만료된 `Session` 행 | 다시 오지 않는 사람의 행이 남았다 | 2026-09-28부터 하루 한 번 지운다(사용자 결정, `lib/daily.ts`) |

## 3. 계정 지우기

마이페이지 "계정 지우기" → 닉네임을 다시 적고 확인하면 `User` 한 행을 지운다(`app/(tabs)/settings/account/actions.ts`).
사용자를 가리키는 표는 모두 `onDelete: Cascade`라 같이 지워진다.

- 지워지는 것: 할 일·카테고리·루틴(건너뛴 날 포함)·일정·반복 일정(뺀 날 포함), 팔로우(양쪽), **내가 친구 할 일에 남긴 반응**, 친구가 내 할 일에 남긴 반응(할 일과 함께),
  로그인 계정·세션, 데스크톱 로그인 코드, 쓴 날짜(`ActiveDay`). `tests/e2e/account.spec.ts`가 확인한다.
- 남는 것과 이유:
  - 오류 기록 — 사용자와 잇지 않는다(화면 경로와 오류 내용 첫 줄뿐). 30일 뒤 지워진다.
  - 하루 합계(`DailyStat`) — 숫자만 있고 사람과 잇지 않는다. 지운 사람도 그날 합계에는 세어진 채 남는다.
  - 백업 — 사고 복구용. VM 파일은 7일 안에, 백업용 Neon은 다음 날 04:00에 덮어써져 사라진다.
  - 서버 프로그램 기록 — 오류 메시지만 남고 30MB를 넘으면 밀려난다.

## 4. 로그·오류 기록에 새는 것

`console.*` 29곳을 모두 봤다. 찍는 것은 id·날짜·반응 종류·오류 메시지뿐이고 이메일·할 일 내용·토큰은 없다.

- 로그인 오류(`lib/auth.ts` logger)는 오류 이름·메시지·제공자 오류 코드만 찍는다. 콜백 쿼리(인가 코드)는 버린다.
- 오류 기록(`lib/errors.ts`)은 **오류 내용 첫 줄만** 남긴다(2026-09-28). Prisma 검사 오류는 둘째 줄부터 넘긴 값(할 일 내용 등)을 적어서다.
  화면 주소는 쿼리를 버린다.
- `errors` 워크플로는 오류 **수만** 받는다. 저장소가 공개라 Actions 기록에 내용을 남기지 않는다.
- 남은 틈: Next가 서버 오류를 Docker 로그에 통째로(스택 포함) 찍는다. Prisma 검사 오류라면 입력값이 섞일 수 있다. VM 안에만 있고 30MB에서 밀려난다.

## 5. 저장소에 새어 나간 비밀 값

전체 히스토리(모든 브랜치)를 확인했다(값은 출력하지 않았다).

- `.env` 계열 파일은 `.env.example`(키 이름만) 말고는 한 번도 커밋되지 않았다. `.gitignore`가 `.env*`를 막는다.
- DB 주소 모양은 `deploy/docker-compose.yml`의 `${POSTGRES_PASSWORD}` 변수 두 줄뿐, Neon 주소·Google 클라이언트 비밀·개인 키·GitHub 토큰·AUTH_SECRET·MONITOR_TOKEN 값은 없다.
- 비밀 값은 VM `/opt/modori/.env`(권한 600)와 GitHub Actions secret에만 있다.

## 6. 백업

이미 정해 운영 중이다. 자세한 것은 `deploy/README.md`.
