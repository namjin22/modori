# 개인정보 목록

실제로 저장하는 개인정보를 코드와 스키마에서 확인한 것만 적는다. 2026-09-28 기준.
새 필드나 새 저장소를 만들면 이 문서와 개인정보처리방침(`lib/privacy.ts`)을 같이 고친다(CLAUDE.md 규칙).

### 데이터베이스 밖

| 항목 | 어디 | 보관 기간 |
|---|---|---|
| 로그인 쿠키 | 브라우저 (`__Secure-authjs.session-token`) | 세션과 같다 |
| 테마(라이트·다크) | 브라우저 localStorage | 브라우저가 지울 때까지 |
| 접속 IP·세션 값 | 서버 메모리의 요청 속도 제한(`lib/rate-limit.ts`) | 10분 안쪽, 재시작하면 사라짐. 저장하지 않는다 |
| 서버 프로그램 기록 | Docker 로그(json-file 10MB × 3) | 30MB를 넘으면 오래된 것부터 |
| 백업 | VM `/opt/modori/backups`(파일 권한 600), 백업용 Neon | VM 7일, Neon은 최신 한 벌(매일 덮어씀) |

Cloudflare(접속을 잇는 곳)와 Google·DataGSM(로그인)은 방침 5번에 적었다.

| `User.grade`, `classNum` | 쓰지 않았고 운영에 값도 없었다 | 2026-09-29 사용자 승인으로 열을 지웠다(마이그레이션 `20260929120000_drop_grade_class`) |
| `User.emailVerified`, `VerificationToken` 표 | 이메일 로그인용. 쓰지 않고 비어 있다 | Prisma 어댑터가 기대하는 모양이라 둔다 |
| 만료된 `Session` 행 | 다시 오지 않는 사람의 행이 남았다 | 2026-09-28부터 하루 한 번 지운다(사용자 결정, `lib/daily.ts`) |

## 3. 계정 지우기

마이페이지 "계정 지우기" → 닉네임을 다시 적고 확인하면 `User` 한 행을 지운다(`app/(tabs)/settings/account/actions.ts`).
사용자를 가리키는 표는 모두 `onDelete: Cascade`라 같이 지워진다.

- 지워지는 것: 할 일·카테고리·루틴(건너뛴 날 포함)·일정, 팔로우(양쪽), **내가 친구 할 일에 남긴 반응**, 친구가 내 할 일에 남긴 반응(할 일과 함께),
  로그인 계정·세션, 데스크톱 로그인 코드, 쓴 날짜(`ActiveDay`). `tests/e2e/account.spec.ts`가 확인한다.
- 남는 것과 이유:
  - 오류 기록 — 사용자와 잇지 않는다(화면 경로와 오류 내용 첫 줄뿐). 30일 뒤 지워진다.
  - 하루 합계(`DailyStat`) — 숫자만 있고 사람과 잇지 않는다. 지운 사람도 그날 합계에는 세어진 채 남는다.
  - 백업 — 사고 복구용. VM 파일은 7일 안에, 백업용 Neon은 다음 날 04:00에 덮어써져 사라진다.
  - 서버 프로그램 기록 — 오류 메시지만 남고 30MB를 넘으면 밀려난다.

## 4. 로그·오류 기록에 새는 것

`console.*` 29곳을 모두 봤다. 찍는 것은 id·날짜·반응 종류·오류 메시지뿐이고 이메일·할 일 내용·토큰은 없다.

- 로그인 오류(`lib/auth.ts` logger)는 오류 이름·메시지·제공자 오류 코드만 찍는다. 콜백 쿼리(인가 코드)는 버린다.
- 오류 기록(`lib/errors.ts`)은 **오류 내용 첫 줄만** 남긴다(2026-09-28). Prisma 검사 오류는 둘째 줄부터 넘긴 값(할 일 내용 등)을 적어서다.
  화면 주소는 쿼리를 버린다.
- `errors` 워크플로는 오류 **수만** 받는다. 저장소가 공개라 Actions 기록에 내용을 남기지 않는다.
- 남은 틈: Next가 서버 오류를 Docker 로그에 통째로(스택 포함) 찍는다. Prisma 검사 오류라면 입력값이 섞일 수 있다. VM 안에만 있고 30MB에서 밀려난다.

## 5. 저장소에 새어 나간 비밀 값

전체 히스토리(모든 브랜치)를 확인했다(값은 출력하지 않았다).

- `.env` 계열 파일은 `.env.example`(키 이름만) 말고는 한 번도 커밋되지 않았다. `.gitignore`가 `.env*`를 막는다.
- DB 주소 모양은 `deploy/docker-compose.yml`의 `${POSTGRES_PASSWORD}` 변수 두 줄뿐, Neon 주소·Google 클라이언트 비밀·개인 키·GitHub 토큰·AUTH_SECRET·MONITOR_TOKEN 값은 없다.
- 비밀 값은 VM `/opt/modori/.env`(권한 600)와 GitHub Actions secret에만 있다.
