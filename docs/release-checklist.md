# 출시 전 체크리스트

이 문서는 실제 사용자를 초대하기 전에 확인할 항목이다. 체크되지 않은 P0가 하나라도
있으면 공개하지 않는다.

## P0: 출시 차단

- [ ] `npm run verify`가 55개 E2E 전체 통과한다.
- [ ] 두 할 일을 동시에 완료해도 진행률과 DB 값이 모두 맞다.
- [ ] Production에서 Google 로그인이 성공한다.
- [ ] DataGSM OAuth의 authorize/token/userinfo URL과 실제 응답을 확보하고 검증한다.
- [ ] Production에 `AUTH_MODE=mock`가 없고 mock 로그인으로 접근할 수 없다.
- [ ] Production DB에 최신 Prisma migration이 적용됐음을 `prisma migrate status`로 확인한다.
- [ ] 계정 삭제가 세션, 할 일, 일정, 반응, 팔로우를 모두 삭제한다.

## P1: 클로즈드 베타 전

- [ ] Android Chrome과 iOS Safari에서 로그인, 추가, 완료, 삭제, 되돌리기를 직접 확인한다.
- [ ] 느린 네트워크에서 중복 제출과 화면 갱신 경합이 재현되지 않는다.
- [ ] `/api/health`가 정상 DB에서 200, DB 장애에서 503을 반환한다.
- [ ] Vercel 로그에서 서버 오류와 DB 연결 오류를 확인할 수 있다.
- [ ] Neon 백업과 복구 절차를 실제로 한 번 실행한다.
- [ ] 공개/비공개 카테고리와 친구 피드 노출 범위를 실제 계정 두 개로 확인한다.
- [ ] 주요 화면의 키보드 포커스, 색상 대비, 모바일 터치 영역을 확인한다.

## P2: 베타 후

- [ ] 첫 화면 TTFB와 cold start를 실제 사용자 지역에서 측정한다.
- [ ] 할 일·카테고리·루틴·일정이 많은 계정의 쿼리와 화면 높이를 점검한다.
- [ ] 토스·카카오 계열의 여백, 버튼 우선순위, 로딩 상태를 기준으로 UI를 다듬는다.
- [ ] 실제 사용 로그를 바탕으로 사용하지 않는 기능과 화면을 줄인다.

## 현재 판정

전체 E2E 55개 중 동시 체크 회귀가 남아 있고, DataGSM OAuth 실응답과 Production
migration 확인이 끝나지 않았다. 친구 3명을 초대하기 전 P0 항목을 모두 닫는다.
