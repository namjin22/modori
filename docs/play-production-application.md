# Google Play 프로덕션 액세스 신청 준비

비공개 테스트(12명 이상, 14일)를 마친 뒤 Play Console **대시보드 → 프로덕션 신청**에서 답하는 질문의 근거와 답안 초안.
질문 문구는 신청 화면에서 다시 확인하고, 아래 초안을 그 칸에 맞게 줄여 넣는다.

## 일정

| 날짜 | 일 |
|---|---|
| 2026-10-14 | 비공개 테스트 버전 게시(버전 코드 11), 테스터 링크 공유, 대시보드에 "12명 이상 참여 선택" 체크 확인 |
| 2026-10-28 무렵 | 14일 충족 → "프로덕션 신청" 버튼이 켜진다(12명이 채워진 날부터 센다) |
| 중간(10/17~21) | 단톡방에 의견 한 번 요청. 받은 의견은 `docs/feedback.md`에 적고 고친 뒤 새 버전을 비공개 테스트에 올린다 |

참여 인원은 대시보드에서는 기준을 넘으면 숫자 대신 체크(✓)로만 보인다. 정확한 수는 **테스트 및 출시 → 테스트 → 비공개 테스트 → (트랙) → 테스터** 탭에서 본다.

## 받은 의견과 고친 것 (근거: `docs/feedback.md`)

출처를 섞지 않는다. 신청서에는 **테스터·사용자 의견**을 앞에 쓰고, 운영자가 직접 써 보며 고친 것은 "내부 점검"으로 따로 쓴다.
모도리는 웹·iOS·안드로이드가 같은 화면 코드를 쓰므로, 웹·아이폰 테스터 의견으로 고친 것도 안드로이드 앱에 그대로 들어갔다.

### 테스터·사용자 의견(친구 테스터, 디스코드 제보, TestFlight)
| 받은 의견 | 고친 것 |
|---|---|
| 친구를 이름으로 직접 검색해야 해서 찾기 어렵다(공개 첫날) | 검색 전에 추천 친구 세 명을 보여 주고 바로 팔로우 |
| 캐나다 친구: 날짜가 하루 앞서 넘어간다 | 사용자별 시간대, 앱은 휴대폰 시간대를 자동으로 따름 |
| 누를 때마다 0.몇 초~몇 초 기다린다 | 한 달치를 한 번에 받아 두고 날짜·체크·옮기기는 바로 반영(서버 응답 전) |
| 폰에서도 주 단위가 아니라 한 달 달력으로 보고 싶다 | 모든 폭에서 한 달 달력 |
| 아이폰: 위아래 배경 어긋남, 사파리로 넘어가는 로그인, 입력칸 확대, 시작 검은 화면, 로그아웃·약관 오류, 새로고침 안 됨 | 배경색·시작 화면, 앱 안 로그인 창, 16px 입력칸, 로그아웃 방식 변경, 당겨서 새로고침 |
| 안드로이드: 프로필 사진 칸을 넘기면 화면 전체가 가로로 늘어난다(가입·프로필 수정) | 칸 안에서만 넘어가게 고침(핫픽스, 시험 추가) |
| 데스크톱 앱이 특정 와이파이에서 연결 안 됨 | 연결 실패 안내·다시 시도 화면(일부 반영, `docs/feedback.md`) |

### 내부 점검(운영자가 폰·PC에서 직접 써 보며)
| 발견한 것 | 고친 것 |
|---|---|
| 폰에서 할 일을 끌면 화면이 같이 스크롤된다, 길게 누르면 링크 메뉴가 뜬다 | 길게 눌러 집기, 폰에서 길게 누르기 메뉴 차단 |
| 처음 로그인하면 크롬 창에서 가입해 웹처럼 보인다 | 크롬 창은 로그인만, 가입은 앱 안에서 |
| 상태·내비게이션 막대 색이 앱과 다르다 | 앱 배경색에 맞춤(버전 코드 11) |
| 안드로이드에 Apple 로그인 버튼이 뜬다, Google 버튼에 로고 없음, 로그인 화면이 스크롤된다 | 안드로이드에서 Apple 숨김, G 로고, 화면에 꽉 차게 |
| 못 끝낸 일을 하나씩 옮기기 번거롭다 | "모두 내일 하기/모두 오늘 하기", 끝낸 일은 "내일 또 하기" |
| 알림이 오지 않는다 | 알림 키 교체 후 확인, 하루 한 번 할 일 리마인드 추가 |
| 일정 색이 한 가지, 순서를 못 바꾼다, 간격이 어색하다 | 색 고르기, 순서 바꾸기, 카드 정리 |

## 답안 초안

**테스터를 어떻게 모았나요?**
> 학교 친구와 지인 15명 안팎을 모아 비공개 테스트 링크를 단톡방으로 공유했습니다. 출시 전부터 웹 버전(modori.site)을 함께 쓰던 사람들이라 실제 사용 환경(학생, 매일 할 일 기록)에 맞는 테스터입니다.

**테스터는 앱을 어떻게 사용했나요? / 참여도는 어땠나요?**
> 테스터들은 날짜별 할 일 적기·체크, 루틴, 일정, 친구 팔로우와 반응 보내기를 썼습니다. 테스트 기간 중 중간에 한 번 사용과 의견을 요청했습니다. (신청 직전에 관리자 지표 화면에서 테스트 기간의 안드로이드 앱 가입·활성 수를 확인해 숫자로 넣는다.)

**어떤 의견을 받았고 어떻게 반영했나요?**
> 위 표에서 고른다. 예: "친구 찾기가 어렵다 → 추천 친구", "시간대가 달라 날짜가 어긋난다 → 사용자별 시간대·휴대폰 시간대 자동", "느리다 → 한 달치 미리 받기와 즉시 반영", "프로필 사진 칸을 넘기면 화면이 늘어난다 → 핫픽스". 의견은 단톡방·디스코드로 받아 기록하고, 고친 버전을 비공개 테스트 트랙에 다시 올렸습니다.

**앱이 프로덕션에 준비됐다고 보는 이유는?**
> 웹 서비스로 먼저 공개해 수십 명이 써 온 기능을 같은 코드로 앱에 담았고, 자동 시험(단위 200여 개×시간대 3, 화면 시험 240여 개)을 매 변경마다 통과시킵니다. 테스트 중 받은 문제는 모두 고쳐 다시 배포했고, 신고·차단, 계정 삭제, 개인정보처리방침을 갖췄습니다.

## 주의
- 안드로이드 비공개 테스트 **기간 안**에 안드로이드 테스터에게서 받은 의견이 아직 적다. 중간 요청으로 안드로이드에서 직접 받은 의견을 두세 개 더 모아 표 맨 위에 넣는다.
- 이름·이메일은 이 문서와 신청서 모두에 적지 않는다.
